## How to Add Screenshots

1. Run the voice agent: `python voice_agent.py`
2. Take a screenshot of the console output
3. Visit your webhook.site URL and take a screenshot of the received payload
4. Save the screenshots in this directory with descriptive names

## Expected Screenshot Content

### Console Output
- Welcome message from the AI assistant
- Name collection prompt and user response
- Requirement collection prompt and user response
- Success confirmation message
- Session summary

### Webhook Output
- JSON payload with name and requirement fields
- Timestamp of the submission
- HTTP 200 response status
